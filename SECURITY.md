## Reporting a Vulnerability

We take the security of Ultimate Gift Cards for WooCommerce seriously. If you discover a security vulnerability, please follow these steps:

### Where to Report

**DO NOT** create a public GitHub issue or WordPress.org support forum post for security vulnerabilities.

Instead, please report security vulnerabilities to:
- **Email**: security@wpswings.com
- **WordPress Security Team**: plugins@wordpress.org (for WordPress.org hosted plugin)
- **Subject Line**: [SECURITY] Ultimate Gift Cards for WooCommerce - [Brief Description]

### What to Include

Please include the following information in your report:

1. **Description**: A clear description of the vulnerability
2. **Impact**: What could an attacker potentially do with this vulnerability?
3. **Steps to Reproduce**: Detailed steps to reproduce the vulnerability
4. **Proof of Concept**: If possible, include a proof of concept
5. **Affected Versions**: Which versions of the plugin are affected
6. **Environment**: PHP version, WordPress version, WooCommerce version
7. **Suggested Fix**: If you have a suggestion for how to fix it (optional)

### What to Expect

- **Acknowledgment**: We will acknowledge receipt of your vulnerability report within 48 hours
- **Assessment**: We will assess the vulnerability and provide an estimated timeline for a fix
- **Communication**: We will keep you informed of our progress
- **Credit**: If you wish, we will credit you in the security advisory (unless you prefer to remain anonymous)
- **Resolution**: We aim to release security patches within:
  - **Critical vulnerabilities**: 7 days
  - **High severity**: 14 days
  - **Medium severity**: 30 days
  - **Low severity**: 60 days

### Disclosure Policy

- Please give us reasonable time to fix the vulnerability before making any information public
- We will coordinate with you on the disclosure timeline
- Once a fix is released, we will publish a security advisory

### Security Best Practices

To keep your installation secure:

1. Always keep the plugin updated to the latest version
2. Use strong, unique passwords for WordPress admin accounts
3. Limit admin and shop manager user access
4. Enable two-factor authentication where possible
5. Regularly backup your site
6. Use HTTPS for your entire site
7. Keep WordPress and WooCommerce up to date

### Past Security Advisories

Security advisories are published at: https://wpswings.com/security-advisories/

### Bug Bounty Program

We currently do not have a bug bounty program, but we greatly appreciate responsible disclosure and will provide public acknowledgment for valid reports.
